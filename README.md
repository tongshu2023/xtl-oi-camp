# 小图灵信奥学习站 · xtl-oi-camp

> CSP-J / GESP 信息学奥赛一站式静态学习站 —— 70 节常规课、76 节 GESP、26 节 CSP-J 内容课和 2 个真题 Boss，双击即用、零后端。
>
> A static, zero-backend learning site for China's CSP-J / GESP informatics-olympiad (competitive programming) prep.

🌐 **在线体验**：<https://tongshu2023.github.io/xtl-oi-camp/>

## 这是什么

小图灵信奥学习站是一套面向信息学奥赛（CSP-J / GESP）的**纯静态**学习站：打开 `index.html` 即可上课，无需注册、无需后端。首页分三栏——常规课、GESP 1–8 级考级课、CSP-J 集训课。

## 已装入的内容

- **常规课**：L1–L4 共 70 节完整课，每节含讲义、C++ 示例、3 道分层练习、答案、3 张记忆卡和 4 道出口测验。
- **GESP 考级课**：1–8 级共 76 节完整课，按 CCF 现行 C++ 认证标准编排。
- **CSP-J 第一轮集训**：8 节主课（每节约 120 分钟）、48 张主动回忆卡、40 道出口小测；所有关卡直接开放，80 分只记录掌握度。
- **复赛专题**：S1–S6 六大算法专题共 18 节真课 + 18 道完整例题 + 36 道洛谷真题（最新一轮，2026-07-22 上线）。
- **真题库**：31 道有道 L3 课后题（题面 / 输入输出 / 样例）；2015–2024 十套第一轮本地试卷与答案，其中 2015–2018 明确标为 NOIP 普及组衔接卷；2025 第一轮等待 CCF 公开题面，不用社区扫描件冒充官方卷。
- **第二轮入口**：2015–2025 年度入口，跳转洛谷进行真实代码提交。
- **学习闭环**：自动冲刺计划、三类课程共用的错题与间隔复习队列。
- **本地阅读笔记**：课程正文选字即可划线或写想法，支持刷新恢复、跨课查看与 JSON 导入导出；数据只留在当前设备的当前浏览器。

## 怎么用

- **学生**：双击 `index.html`（或访问上方在线地址）即可上课；进度与阅读笔记保存在本地浏览器，第一版无需账号。笔记可在「我的笔记」中导出备份。
- **教师**：备课口令 `xtl2026`（见 `data/config.js`），开启后可看答案、参考代码、授课提示，并切换投屏视图。
- **CSP-J 强化台**：`cspj-lab.html` 提供更细的模考、错题本和代码草稿。

## 本地运行 / 部署

纯静态站，无构建步骤：

- 直接双击 `index.html`；或
- 用任意静态服务器托管，如 `python -m http.server`，再访问 `http://localhost:8000/`；或
- 把整个目录部署到任意静态托管——本仓已通过 GitHub Pages 上线（见上方地址）。

## 当前边界（诚实说明）

- 本站为**静态站**，不含统一学生账号与教师后台；学习进度和笔记只存于当前浏览器，换设备不同步。
- 真题以本地 PDF 与结构化数据（`data/`、`content_staging/`）承载，缺失年份明确标注、不冒充真题。

## 数据校验 / 测试

`data/` 里的题库、真题、课程都是纯数据，最容易在后续灌装内容时出现"答案下标错位""真题卷引用了不存在的题""交付清单对不上"这类隐蔽错误。仓库已内置一组**零第三方依赖**的数据完整性校验（用 Node 内置 `node:test` 与 `node:vm` 在无浏览器环境加载 `data/*.js`）：

```bash
npm run check   # 加载全部数据并打印内容清单（快速自检）
npm test        # 运行数据完整性断言
```

阅读笔记和宽屏/手机布局另有真实 Chromium 端到端验收脚本 `e2e/notes-browser.mjs`、`e2e/layout-browser.mjs`。在已启动 Chrome DevTools 端口（默认 `127.0.0.1:9338`）时，分别运行 `npm run test:notes:e2e`、`npm run test:layout:e2e`。

校验内容包括：70+76 节课程内容合同、GESP 修订边界、初赛题/课程小测答案下标、正式入口脚本链、真题引用、题目 ID、年份、复赛 18 节讲义与参考代码补丁符号。改数据后先跑一遍即可挡住多数低级回归。

## 目录结构

- `index.html` / `academy.html` / `cspj-lab.html` —— 三个入口页
- `app.js` / `store.js` / `academy-app.js` / `academy-store.js` —— 前端逻辑与本地存储

- `content_staging/` —— 历年真题 PDF 原件
- `DELIVERY.md` —— 交付说明与课上使用指南
